# API Alignment: Frontend ↔ Contract v1

How the frontend maps onto [API_CONTRACT.md](API_CONTRACT.md), where the contract and the
designs disagree, and what we need the backend to answer. Item IDs (M1, Q3…) are referenced from
code comments in `frontend/src/types/api/`, so keep the numbering stable. Mark items resolved; don't delete them.

**Status legend:** 🔴 blocks a planned phase · 🟡 workaround in place, should fix · ⚪ clarification

## 1. What the frontend now does

| Contract rule                     | Frontend implementation                                                                                                                              |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Base URL `/api/v1`                | `VITE_API_BASE_URL` defaults to `/api/v1`. Vite proxies `/api` and `/static` to FastAPI in dev                                                       |
| Error envelope `{ error: {…} }`   | `ApiError` exposes `status`, `code`, `message`, `details[]`, `timestamp`, `fieldErrors`. It also parses FastAPI's default `{ detail }` as a fallback |
| Bearer JWT                        | `Authorization: Bearer <access_token>` attached automatically from `tokenStorage`                                                                    |
| 401                               | Tokens cleared, then a registered handler runs (redirects to `/login` from Phase 5)                                                                  |
| JSON + multipart upload           | `api.get/post/put/patch/delete` + `api.upload(path, { file })`                                                                                       |
| Query params                      | `query` option. `undefined` values skipped, arrays repeated                                                                                          |
| Inches, top-left origin           | UI keeps the user's unit and converts at the boundary (`lib/units.ts`)                                                                               |
| Money as decimal strings          | Typed as `DecimalString`, displayed only via `formatMoney()`. No client-side arithmetic                                                              |
| Relative asset URLs (`/static/…`) | `resolveApiUrl()` resolves them against the API origin                                                                                               |
| Every endpoint                    | Paths in `services/endpoints.ts`. Request/response types in `types/api/*` (snake_case, 1:1 with the wire)                                            |

Endpoint functions and live calls are **not** wired yet (Phase 5).

## 3. Questions for the backend

| ID  | Status     | Question                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

(Frontend has one `EntityId` alias, so either is a one-line change. It just needs deciding.)                                                                                                                                                                                                                                                          |
| Q2  | 🟡 planned | **(Backend: will be added; integrate in the final phase.)** **Session lifetime:** a `refresh_token` is returned, but there's no `POST /auth/refresh` and no `POST /auth/logout`. With `expires_in: 3600`, users get logged out after an hour. | Q3  | 🟡         | **Token transport:** tokens in the response body have to sit in localStorage, where XSS can reach them. Could the refresh token be an httpOnly, Secure, SameSite cookie, with the access token kept in memory? Frontend storage is isolated in `services/tokenStorage.ts`, so switching is cheap.                                                                                                                                                                                                         |
| Q4  | ⚪         | **Origins/CORS:** what's the production API origin? Is `/static/*` served from the same host? If cross-origin, `Authorization` must be in `allow_headers`.                                                                                                                                                                                                                                                                                                                                                |
| Q5  | 🔴         | **Photo URLs vs Bearer auth:** `thumbnail_url`/`preview_url` are API paths. If they need the Bearer header, `<img src>` **can't load them** (browsers don't send custom headers for images). Options: signed, short-lived URLs (preferred), public unguessable URLs, or cookie auth.                                                                                                                                                                                                                      |
| Q6  | 🟡         | Full enums for `layout_style` and `target_alignment` in generate-layout?                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Q7  | ⚪         | **Money:** the contract allows strings _or_ floats. Can we commit to decimal strings everywhere? | Q8  | ⚪         | **Totals:** the version's `estimated_price.total` (4176.02) excludes shipping, but the quote's `total_estimated` (4526.02) includes it. Is that intended? Is it mislabelled?                                                                                                                                                                                                                                                  |
| Q9  | 🟡         | Full enums for `glass_type`, `matboard_type`, `wall.texture`, design `status`, quote `status`, and `UserRole`?                                                                                                                                                                                                                                                                                                                                                                                            |

| Q18 | ⚪         | **Input limits & error text:** the UI caps email/identifier at 254 and password at 128 chars. ## 4. Change process

1. Backend updates `API_CONTRACT.md`.
2. Frontend updates `src/types/api/*` and `services/endpoints.ts` in the same PR, then marks the item here as ✅ with the date.
